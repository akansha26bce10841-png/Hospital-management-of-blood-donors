# Project Title
Hospital Blood Donor Management System


## 1. Problem Statement

Managing blood donor information manually can be difficult, especially when a hospital needs to quickly find donors with a particular blood group. Manual records may take more time to search, update, or maintain.

To address this, a simple Python-based Hospital Blood Donor Management System is required to store donor details, search donors by blood group, update or delete records, and generate basic blood group reports. The project will use lists, strings, conditional statements, loops, and functions to demonstrate fundamental Python programming concepts.


## 2. Scope of the Project

### In Scope

- Registration of new blood donors
- Storage of donor details using Python lists
- Display of all registered donors
- Searching for donors based on blood group
- Updating donor contact and city details
- Deleting donor records
- Basic validation of age, blood group, and phone number
- Counting donors according to blood group
- Menu-driven program using loops and conditional statements
- Modular and function-based Python code

### Out of Scope

- Online donor registration
- Real-time hospital or blood-bank database connection
- Automatic blood donation eligibility decisions
- Medical diagnosis or medical advice
- Online notifications or SMS services
- Web or mobile application interface unless added manually
- Advanced database management unless added manually


## 3. Target Users

- Hospital staff managing donor records
- Blood bank staff
- Students learning Python programming
- Beginners learning lists, strings, loops, conditional statements, and functions
- Anyone interested in maintaining a simple donor record system


## 4. High-Level Features

- Menu-driven donor management system
- Add new donor records
- View all registered donors
- Search donors by blood group
- Update donor information
- Delete donor records
- Validate basic donor information
- Display blood group-wise donor count
- Display total number of registered donors
- Modular, clear, and well-commented Python code
